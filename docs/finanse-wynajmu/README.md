# Finanse wynajmu — materiały robocze

Folder na pliki wejściowe do prac nad modułem finansowym wynajmu
(np. arkusze cenowe, zestawienia, wzory rozliczeń, przykłady faktur,
notatki wymagań).

Materiały tu wrzucane traktujemy jako **dane wejściowe / referencję** —
nie jako część kodu aplikacji. Właściwa implementacja trafi do `src/`,
`prisma/` itd. według normalnych konwencji repo (patrz `README.md`).
